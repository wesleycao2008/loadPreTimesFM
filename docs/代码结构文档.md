# 兰州负荷预测系统 - 代码结构文档

## 1. 项目概述

本项目使用两种先进的零样本时间序列预测模型（Google TimesFM 2.5 和 Amazon Chronos-2）对兰州地区的电力负荷数据进行预测。项目支持动态协变量以提升预测精度，支持小时级和15分钟级两种预测粒度，并提供滚动预测功能。

## 4. 核心模块详解

### 4.1 forecast_chronos.py - Chronos-2 小时级预测

**功能**: 使用 Amazon Chronos-2 模型进行零样本负荷预测（小时级）

**主要配置**:
| 配置项 | 值 | 说明 |
|--------|------|------|
| TARGET_VAR | "LOAD" | 目标预测变量 |
| HORIZON_HOURS | 240 | 预测时长（10天×24小时） |
| SPLIT_DATE | 2024-06-25 | 训练/预测分界日期 |
| COVARIATES | WBGT, ICHB, ET, THI, CHI | 动态数值协变量 |

**执行流程**:
```
[1/7] 读取数据并验证必要列
[2/7] 构造 Chronos-2 输入格式（long-format），重采样到小时级
[3/7] 加载 Chronos-2 模型（从 HuggingFace 下载）
[4/7] 执行 pipeline.predict_df 预测
[5/7] 计算误差指标（MAE, RMSE, MAPE, Coverage）
[6/7] 保存 CSV 结果
[7/7] 绘制预测图表并保存
```

**命令行参数**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| --input | data/lanzhouNew2022-2024.xlsx | 输入文件路径 |
| --output-dir | output | 输出目录 |
| --model | amazon/chronos-2 | 模型名称 |
| --device | cuda | 运行设备（cuda/cpu） |
| --context-length | None | 最大上下文长度 |
| --batch-size | 1 | 推理批次大小 |

**输出文件**:
- `output/load_forecast_chronos_10days.csv` - 包含 LOAD_ACTUAL, LOAD_PRED, LOAD_MEAN, LOAD_Q10, LOAD_Q90
- `output/load_forecast_chronos_10days.png` - 预测可视化图表

### 4.2 forecast_chronos_15min.py - Chronos-2 15分钟级预测

**功能**: 使用 Amazon Chronos-2 模型进行15分钟级零样本负荷预测，支持滚动预测，并写入达梦数据库

**主要配置**:
| 配置项 | 值 | 说明 |
|--------|------|------|
| TARGET_VAR | "y" | 目标预测变量 |
| HORIZON_DAYS | 10 | 预测天数 |
| STEPS_PER_DAY | 96 | 每天96条（15分钟/条） |
| HORIZON_STEPS | 960 | 总预测步数（10天×96） |
| FREQ | "15min" | 数据频率 |
| SPLIT_DATE | 2025-12-22 | 训练/预测分界日期 |
| COVARIATES | TEMPERATURE, RADI | 动态数值协变量 |

**执行流程**:
```
[1/4] 读取数据并验证必要列
[2/4] 加载 Chronos-2 模型（从 HuggingFace 下载）
[3/4] 执行滚动预测（每个日期调用 _run_single_forecast）
     └─ _run_single_forecast 内部流程:
        [1/7] 按日期切分上下文和预测期数据
        [2/7] 构造 Chronos-2 输入格式（long-format），重采样到15分钟级
        [3/7] 执行 pipeline.predict_df 预测
        [4/7] 计算误差指标（MAE, RMSE, MAPE, Coverage）
        [5/7] 保存 CSV 结果
        [6/7] 写入达梦数据库
        [7/7] 绘制预测图表并保存
[4/4] 汇总滚动预测结果
```

**命令行参数**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| --input | data/dm_output.xlsx | 输入文件路径 |
| --output-dir | output | 输出目录 |
| --model | amazon/chronos-2 | 模型名称 |
| --device | cuda | 运行设备（cuda/cpu） |
| --split-date | 2025-12-22 | 单次预测起始日期 |
| --start-date | None | 滚动预测开始日期（需与 --end-date 配合） |
| --end-date | None | 滚动预测结束日期（需与 --start-date 配合） |
| --context-length | None | 最大上下文长度 |
| --batch-size | 1 | 推理批次大小 |
| --db-host | 127.0.0.1 | 达梦数据库地址 |
| --db-port | 5236 | 达梦数据库端口 |
| --db-user | RES2000_FJ | 达梦数据库用户名 |
| --db-password | damengres2000 | 达梦数据库密码 |
| --db-table | "RES2000_FJ"."RES_CON_PWRGRID_F_FORECAST_2025" | 目标表名 |
| --fill-v2400 | next_day_first | V2400填充策略 |
| --skip-db | False | 跳过数据库写入 |

**滚动预测功能**:
- 通过 `--start-date` 和 `--end-date` 指定起止日期，系统按天为单位执行滚动预测
- 每个日期预测未来10天
- 输出文件按日期后缀命名（如 `load_forecast_chronos_15min_20250601_10days.csv`）
- 单次预测时使用 `--split-date` 参数

**数据库表结构**:
- 主键列: ID, MEAS_TYPE, DATASOURCE_ID, FORECAST_TYPE, FB_TIME, YB_TIME, FB_SEQ
- 元数据列: FORE_CYCLE, UPDATE_TIME
- 数据列: V0000~V2345（每15分钟一个值）, V2400（可选）

**输出文件**:
- `output/load_forecast_chronos_15min_10days.csv` - 单次预测结果
- `output/load_forecast_chronos_15min_10days.png` - 单次预测图表
- `output/load_forecast_chronos_15min_YYYYMMDD_10days.csv` - 滚动预测结果
- `output/load_forecast_chronos_15min_YYYYMMDD_10days.png` - 滚动预测图表

## 6. 运行方式

```bash
# TimesFM 预测（小时级）
python forecast_nextload.py

# Chronos-2 预测（小时级）
python forecast_chronos.py

# Chronos-2 预测（15分钟级，单次预测）
python forecast_chronos_15min.py --split-date 2025-12-22

# Chronos-2 预测（15分钟级，滚动预测）
python forecast_chronos_15min.py --start-date 2025-12-22 --end-date 2025-12-31

# Chronos-2 预测（15分钟级，跳过数据库写入）
python forecast_chronos_15min.py --split-date 2025-12-22 --skip-db

# 对比两种预测结果
python compare_forecasts.py
```

## 7. 误差指标说明

| 指标 | 公式 | 说明 |
|------|------|------|
| MAE | mean(\|actual - pred\|) | 平均绝对误差 |
| RMSE | sqrt(mean((actual - pred)²)) | 均方根误差 |
| MAPE | mean(\|actual - pred\| / actual) × 100 | 平均绝对百分比误差 |
| Coverage | mean((actual ∈ [q10, q90])) × 100 | 预测区间覆盖率 |

## 8. 协变量处理

### 8.1 小时级预测协变量
- **WBGT**: 湿球黑球温度 - 综合热环境指标
- **ICHB**: 室内热辐射指标
- **ET**: 蒸发蒸腾量
- **THI**: 温湿指数
- **CHI**: 热指数

### 8.2 15分钟级预测协变量
- **TEMPERATURE**: 温度
- **RADI**: 辐射量

协变量在预测期需要预先已知，用于提升预测精度。
