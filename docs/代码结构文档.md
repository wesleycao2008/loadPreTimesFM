# 兰州负荷预测系统 - 代码结构文档

## 1. 项目概述

本项目使用两种先进的零样本时间序列预测模型（Google TimesFM 2.5 和 Amazon Chronos-2）对兰州地区的电力负荷数据进行预测。项目支持动态协变量（WBGT、ICHB、ET、THI、CHI）以提升预测精度，预测未来 10 天（240 小时）的负荷值。

## 2. 目录结构

## 3. 数据字段说明

| 字段名 | 说明 |
|--------|------|
| DATATIME | 时间戳（小时级别） |

## 4. 核心模块详解

### 4.1 forecast_chronos.py - Chronos-2 预测

**功能**: 使用 Amazon Chronos-2 模型进行零样本负荷预测

**主要配置**:
| 配置项 | 值 | 说明 |
|--------|------|------|
| TARGET_VAR | "LOAD" | 目标预测变量 |
| HORIZON_HOURS | 240 | 预测时长（10天×24小时） |
| SPLIT_DATE | 2024-06-25 | 训练/预测分界日期 |
| ID_COLUMN | "item_id" | 序列标识列 |
| TIMESTAMP_COLUMN | "DATATIME" | 时间戳列 |

**执行流程**:
```
[1/7] 读取数据并验证必要列
[2/7] 构造 Chronos-2 输入格式（long-format），重采样到小时级
[3/7] 加载 Chronos-2 模型（从 HuggingFace 下载）
[4/7] 执行 pipeline.predict_df 预测
[5/7] 计算误差指标（MAE, RMSE, MAPE, Coverage）
[6/7] 保存 CSV 结果
[7/7] 绘制预测图表并保存
```

**命令行参数**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| --input | data/lanzhouNew2022-2024.xlsx | 输入文件路径 |
| --output-dir | output | 输出目录 |
| --model | amazon/chronos-2 | 模型名称 |
| --device | cuda | 运行设备（cuda/cpu） |
| --context-length | None | 最大上下文长度 |
| --batch-size | 1 | 推理批次大小 |

**输出文件**:
- `output/load_forecast_chronos_10days.csv` - 包含 LOAD_ACTUAL, LOAD_PRED, LOAD_MEAN, LOAD_Q10, LOAD_Q90
- `output/load_forecast_chronos_10days.png` - 预测可视化图表

---

### 4.2 forecast_nextload.py - TimesFM 2.5 预测

**功能**: 使用 Google TimesFM 2.5 模型进行带协变量的负荷预测

**主要配置**:
| 配置项 | 值 | 说明 |
|--------|------|------|
| TARGET_VAR | "LOAD" | 输入历史负荷列 |
| HORIZON_HOURS | 240 | 预测时长 |
| MAX_CONTEXT | 8192 | 最大上下文长度 |
| MAX_HORIZON | 256 | 最大预测长度 |
| SPLIT_DATE | 2024-06-25 | 训练/预测分界日期 |

**执行流程**:
```
[1/7] 读取数据并验证必要列
[2/7] 构造 LOAD 上下文序列与协变量矩阵
[3/7] 加载 TimesFM 2.5 模型（约800MB权重）
[4/7] 执行 forecast_with_covariates 预测
[5/7] 计算误差指标（MAE, RMSE, MAPE, Coverage）
[6/7] 保存 CSV 结果
[7/7] 绘制预测图表并保存
```

**命令行参数**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| --input | data/lanzhouNew2022-2024.xlsx | 输入文件路径 |
| --output-dir | output | 输出目录 |

**输出文件**:
- `output/load_forecast_10days.csv` - 包含 LOAD_ACTUAL, LOAD_PRED, LOAD_MEAN, LOAD_Q10, LOAD_Q90
- `output/load_forecast_10days.png` - 预测可视化图表

### 4.3 compare_forecasts.py - 预测对比

**功能**: 读取两种模型的预测结果，计算并对比误差指标

**执行流程**:
```
1. 读取两个模型的 CSV 输出文件
2. 计算 Chronos-2 的 MAE, RMSE, MAPE
3. 计算 TimesFM 的 MAE, RMSE, MAPE
4. 输出对比表格并标注更优者
5. 计算改进幅度百分比
```

## 7. 误差指标说明

| 指标 | 公式 | 说明 |
|------|------|------|
| MAE | mean(\|actual - pred\|) | 平均绝对误差 |
| RMSE | sqrt(mean((actual - pred)²)) | 均方根误差 |
| MAPE | mean(\|actual - pred\| / actual) × 100 | 平均绝对百分比误差 |
| Coverage | mean((actual ∈ [q10, q90])) × 100 | 预测区间覆盖率 |

## 8. 协变量处理

两种模型均使用以下 5 个动态数值协变量：
- **WBGT**: 湿球黑球温度 - 综合热环境指标
- **ICHB**: 室内热辐射指标
- **ET**: 蒸发蒸腾量
- **THI**: 温湿指数
- **CHI**: 热指数

协变量在预测期需要预先已知，用于提升预测精度。
